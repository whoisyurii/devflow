# Scoped local agents and notifications

Match a configured repository by Git common directory and allow React.BFF (including ClientApp) inside its main checkout and linked worktrees. Repository-root sessions are an explicit preference. Resolve worktree root and branch per event; keep sessions keyed by provider and session ID. Apply scope before ingestion and to imported/cached sessions. Never infer permission decisions.

Reuse Coucou's main-tool/optional-integration model. A local Both/Codex/Claude Code setting controls visible sessions and agent alerts. Single-agent mode widens the focus card and uses three stacked shortcut pills; the header and Settings can switch providers without losing in-scope history.

Completed turns, permission requests, input questions and failures create durable context-rich notices. Show provider, session name, worktree, branch and pending summary in the notch and system banner. An original short synthesized chime is optional, with preview/test controls. Hook installation retains preview/merge/backup and Codex trust requirements; do not install Claude WorktreeCreate because that replaces Git creation rather than observing it.

Verify real linked Git worktrees, excluded projects, simultaneous sessions, missing/deleted paths, both provider schemas, notification deduplication, silent history, and relay output. Build and exercise the native layout, chime and notice previews. Run harmless CLI smoke tests when local authentication and hook trust permit, reporting any limitations accurately.
